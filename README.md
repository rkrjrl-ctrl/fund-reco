# 펀드추천 대시보드

페이지: https://rkrjrl-ctrl.github.io/fund-reco/ (매일 08:30·19:30 KST 자동 갱신)

## 라인업 바꾸는 법
GitHub에서 `lineup.json` → 연필(Edit) 아이콘 → 수정 → Commit. 저장하면 약 6분 뒤 페이지에 반영됩니다.

- 한 줄(`묶음`/`유형`/`펀드명`/`특징`/`비고`)이 라인업 표의 한 행이고, `종목`에 그 행의 펀드(클래스)들을 넣습니다.
- `묶음`: 1,2,3 = 표의 구역 번호
- **TDF**: `{ "코드": "069083" }` 만 쓰면 됩니다(한국투자증권 TDF 전체가 이미 수집됨).
- **한국투자증권 일반 펀드**: `{ "코드": "073101", "짧은이름": "AB미국그로스", "한투검색어": "AB미국그로스" }`
  (검색어로 한국투자증권 펀드몰에서 검색해 코드가 나오는 이름을 넣으세요)
- **FunETF 펀드**(한국투자증권에 없는 것): `FunETF코드, 기간(36|12), 기준(first|unit), 운용사, 총보수, 위험등급, 설정일, 설정액억, 정식명, 메모, 보유종목` 필요. 기존 두 개를 복사해 고치세요.
- 코드를 찾지 못하면 갱신이 실패하고 기존 페이지는 그대로 유지됩니다(Actions 탭에서 확인).

## 보유종목
한국투자증권 펀드는 매 실행마다 8회까지 재시도해 가져오고, 성공하면 `holdings.json`에 저장합니다. 끝내 실패하면 마지막 성공값을 쓰고, 그것도 없으면 갱신을 중단합니다.

## 변액(메트라이프생명) 탭
- 데이터: 메트라이프생명 공시실 > 변액보험공시 > 기준가 현황(로그인 불필요). 동행·동행 Plus(현재+과거 버전)·실버플랜 변액유니버셜에서 선택 가능한 펀드 38개의 일별 기준가를 설정일부터 수집합니다.
- `metlife-cache.json`에 쌓아 두고 매일 최근 7일분만 다시 받습니다. 사이트 오류 시 캐시로 진행합니다.
- 탭: "변액 펀드 비교"(TDF 탭과 같은 UI), "조합 시뮬레이터"(비중 입력 → 조합 수익률·변동성·MDD, 리밸런싱 선택).
- 변액 비교 탭: 가입 상품(동행/동행Plus/실버플랜)·가입 시점(월)·기간(프리셋 또는 직접 지정)을 고르면, 그 시점에 해당 상품 버전에서 고를 수 있던 펀드만 보여주고 가입 시점부터의 수익률·연환산·변동성·MDD를 계산합니다. 상품 버전별 선택 가능 펀드는 메트라이프 공시에서 자동으로 읽습니다(`metlife-cache.json`의 `_eras`).
- 조합 시뮬레이터: 초기 일시금 + 월 납입(적립식, 납입 횟수 지정), 리밸런싱, 원금 대비 수익률·IRR·평가금액 추이.

## TDF 구성·특징, 기간 리포트

- 주식·채권 비중, 주요 보유, 변동성은 한국투자증권 공시에서 매일 자동 수집합니다(	dfinfo.json에 직전 값 보관).
- 운용사별 특징 문구는 	df-notes.json에서 고칩니다. 상품군 이름의 앞부분이 일치하면 적용됩니다.
- TDF 기간 리포트 탭의 설명 문장은 수익률과 공시 자료로 자동 계산됩니다.

- 리포트의 시장 배경(환율·지수·금리·금)은 같은 계정의 `claude_drive` 저장소 `data/long_term/*.csv`, `data/history.csv`를 읽어 씁니다. 변액 기간 리포트도 같은 방식입니다.


## 펀드 구성 자료와 순위 이유

- TDF: 한국투자증권에 공시된 보유 상위 종목을 이름으로 분류해 자산군 비중(국내주식·미국주식·기타 해외주식·국내채권·해외채권·금·현금성)을 추정합니다.
- 변액: 메트라이프 공시실 운용현황(자산구성·순자산, 월말 기준)을 자동 수집하고, 자산군 비중과 설명은 `metlife-notes.json`(운용설명서의 투자대상·환헤지 방침 정리)에서 고칩니다.
- 환노출은 최근 3년 월간 수익률이 원/달러 환율에 반응한 정도로 추정합니다.
- 기간 리포트의 순위 이유는 "또래 평균 대비 자산군 비중 차이 × 그 자산의 기간 수익률"로 계산합니다.
